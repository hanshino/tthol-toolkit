# 技能清單直接讀取：調查紀錄

2026-10-02。推算屬性公式時，需要把「加體力 / 真氣上限」的被動技能（養精蓄銳、強筋健骨、經脈點……）從上限扣掉，所以要知道角色學了哪些技能、各幾級。技能清單跟背包一樣，是角色物件（`CCharObject`）裡的「數量 + 指標陣列」，不用掃描。遊戲執行中實測過，跟遊戲畫面一致。

已實作：`reader.read_skills(pm, hp_addr)` → `[(magic_id, level)]`，測試在 `tests/test_direct_skills.py`。worker 每次 poll 讀一次，用 `reader.load_magic_db()` 補上名稱和最高等級，經 `CharacterDetail.skills` 送到前端，顯示在「根脈」分頁的「武學」區塊（等級 / 最高等級，滿級標金色）。另一台 Lv200 角色實測 107 個技能，名稱全部對得上、沒有等級超過上限的。

## 欄位（相對 HP 位址）

| HP 相對 | 物件相對 | 型別 | 內容 | 依據 |
|---|---|---|---|---|
| `+0xF4`（244） | `+0x3BC` | int32 | **技能數** | 實測 41（天外天 Lv84）、72（惡人谷 Lv192） |
| `+0xF8`（248） | `+0x3C0` | ptr | → `u16[技能數]`，技能 ID（`magic.id`），由小到大 | 41 個 ID 全部在 `magic` 表裡 |
| `+0xFC`（252） | `+0x3C4` | ptr | → `u8[技能數]`，技能等級（`magic.level`），跟 ID 陣列一一對應 | 養精蓄銳 (24) = 6，跟遊戲一致 |
| `+0x100`（256） | `+0x3C8` | ptr | → 第三個平行陣列 | 實測全 0，**意義未確認**（冷卻？熟練度？） |

`(id, level)` 對 `tthol.sqlite` 的 `magic (id, level)` 就能查名稱和說明；加成數值在 `magic_stats`（例如 `stat = 'HPMAX' / 'MPMAX'`）。

## 讀法

```
count  = read_i32(hp_addr + 0xF4)
ids    = read_u16_array(read_u32(hp_addr + 0xF8), count)
levels = read_u8_array (read_u32(hp_addr + 0xFC), count)
skills = zip(ids, levels)
```

`read_skills` 會先確認 `hp_addr - 0x2C8` 是 `CCharObject` 的 vtable，數量超出 0..1000 或指標不在 heap 範圍就丟 `ValueError`，跟 `read_item_container` 同一套防呆。

## 怎麼找到的

1. 已知條件：角色有「養精蓄銳 Lv6」（`magic.id = 24`）。
2. 用幾種編碼掃全記憶體找 `(24, 6)`，並要求前後連續幾筆也都是合法的 `(magic.id, level ≤ 最高等級)`：
   - `id × 100 + level` 的 dword：只找到 MAGIC 表本身（2403..2410），不是角色資料。
   - `(u16 id, u8 level)` 緊密排列：找到 41 筆，但所在區塊開頭是 `0x3008` + 前後指標，屬於收封包用的 buffer 串列（tag 0x3008 / 0x200 / 0x30），內容會被覆寫，不能拿來讀。
3. 改成只找「ID 依序排列」的陣列（181, 182, 184, 185, 186… 間隔 2 bytes），在一個獨立的 heap 區塊找到 u16 ID 陣列；再在附近找同順序的等級 bytes，找到 u8 等級陣列（另一個區塊）。
4. 反查指向這兩個陣列開頭的指標：剛好落在 HP 位址 `+0xF8` / `+0xFC`，前一格 `+0xF4` = 41 = 技能數。

## 用途：扣掉加體力 / 真氣的被動

這些技能會加上限（`magic_stats` 的 `HPMAX` / `MPMAX`，或 `magic.help` 的文字）：養精蓄銳 24（真氣 +20..200）、強筋健骨 53（體力 +30..300）、氣通八脈 601、鍛筋鍊髓 602、經脈的章門 1040 / 京門 1060 / 通谷 1100 / 幽門 1115、體力 / 真氣增加 1151 / 1152 / 1181 / 1182 / 1195 / 1196、獎勵增加 1159。實例：天外天 Lv84 的真氣基礎值扣掉養精蓄銳 Lv6 的 105 之後，剛好等於 `7 × 等級 + 40`。

## 待解問題

1. `+0x100` 第三個平行陣列是什麼。
2. 學新技能 / 升級時陣列是否重新配置（指標會不會變）。目前每次都從 `hp_addr` 重讀，所以不影響。
3. compat 佈局的角色（HP/MP current↔max 對調）位移是否一樣。`read_skills` 對不上 `CCharObject` 會回 `None`，不會讀到錯的指標。
